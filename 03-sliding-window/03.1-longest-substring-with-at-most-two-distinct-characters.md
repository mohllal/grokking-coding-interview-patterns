# Longest Substring with At Most Two Distinct Characters

## Problem description

Given a string `s`, find the length of the longest substring that contains at most two distinct characters.

## Examples

**Example 1:**

```plaintext
Input: s = "eceba"
Output: 3
Explanation: The substring is "ece" which has length 3.
```

**Example 2:**

```plaintext
Input: s = "ccaabbb"
Output: 5
Explanation: The substring is "aabbb" which has length 5.
```

## Constraints

- `1 <= len(s) <= 10^5`
- `s` consists of English letters

## Hints

<details>
<summary>Hint 1</summary>

"At most two" is a specific case of "at most `k`". You have already written this loop.

</details>

<details>
<summary>Hint 2</summary>

Fixing the bound at two means the frequency map can never hold more than three keys. What does that do to the space complexity?

## Solution

### Intuition

This is [Longest Substring with K Distinct Characters](./03-longest-substring-with-k-distinct-characters.md) with `k` hard-wired to `2`. Grow the window, and whenever it holds a third distinct character, shrink from the left until only two remain.

```plaintext
s = "ccaabbb"

c        {c:1}              valid     length 1
cc       {c:2}              valid     length 2
cca      {c:2, a:1}         valid     length 3
ccaa     {c:2, a:2}         valid     length 4   <- best so far
ccaab    {c:2, a:2, b:1}    3 > 2, shrink from the left
 caab    {c:1, a:2, b:1}    still 3, shrink
  aab    {a:2, b:1}         valid     length 3
  aabb   {a:2, b:2}         valid     length 4
  aabbb  {a:2, b:3}         valid     length 5   <- best

answer = 5
```

### Algorithm

1. Add `s[window_end]` to the frequency map
2. While the map holds more than two keys, decrement the count of `s[window_start]`, remove the key if it reaches zero, and advance `window_start`
3. Record `window_end - window_start + 1` as a candidate for the longest length

### Complexity analysis

- Time complexity: $O(n)$ — each character is inserted once and removed at most once.
- Space complexity: $O(1)$ — the map holds at most three keys at any moment, a fixed bound rather than one that grows with the input.

```python
from collections import Counter


class Solution:
    def length_of_longest_substring_two_distinct(self, s: str) -> int:
        longest_length = 0

        window_start = 0
        window_counter = Counter()
        for window_end in range(len(s)):
            window_counter[s[window_end]] += 1

            while len(window_counter) > 2:
                start_character = s[window_start]
                window_counter[start_character] -= 1

                if window_counter[start_character] == 0:
                    del window_counter[start_character]

                window_start += 1

            longest_length = max(longest_length, window_end - window_start + 1)

        return longest_length
```

## Relationship to the general and disguised forms

- [Longest Substring with K Distinct Characters](./03-longest-substring-with-k-distinct-characters.md) is the general version. Substituting `k = 2` gives exactly the loop above. The only real consequence is the space bound: $O(k)$ becomes $O(1)$ once `k` stops growing with the input.
